# Termux Cleanup

## Когда использовать

- Пользователь жалуется на нехватку места / медленную работу.
- В `~/` больше 3 ГБ и явно есть кеши.
- После установки/удаления многих npm-пакетов или запуска `npx`.
- Периодическая профилактика (раз в 1–2 недели).

## Что можно чистить безопасно

| Что | Где | Комментарий |
|------|------|-------------|
| apt-кеш | `pkg clean` | Всегда безопасно |
| npm cacache и логи | `~/.npm/_cacache`, `~/.npm/_logs`, `~/.npm/_npx` | Перекачается при нужде |
| node-gyp | `~/.cache/node-gyp` | Перекачается при нужде |
| pip-кеш | `~/.cache/pip` | Перекачается при нужде |
| **старые версии pnpm store** | `~/.local/share/pnpm/store/v<N>` — все, кроме последнего `v<N>` | Активную версию **не трогать** |
| одноразовые tarball инсталляторы | `~/*.tgz`, `~/*.tar.gz` в home | Проверить дату и что тул уже установлен |
| пустые тестовые venv | `~/test_venv`, `~/tmp_env` и т.п. | Только если явно не используется |

## Что НЕ трогать никогда

- **data-директории установленных программ и CLI-агентов** — любой `~/.<progname>` (напр. `~/.happy`, `~/.claude`, `~/.gemini`, `~/.codex`, `~/.hermes`, `~/.omnara`, `~/.agents`). Это живые данные, не кеш. Перед удалением проверить, что программа реально ставилась: `which <name>`, обёртки в `~/bin/`, симлинки в `/usr/bin/`.
- `~/.termux/` — конфиги самого Termux (шрифты, keys, свойства).
- `~/.config/` кроме явно временных подпапок — конфиги приложений.
- `~/.local/share/pnpm/store/v<последний>` — активный pnpm-кеш.
- Любые папки проектов пользователя (`~/GeminiTelegramBot`, `~/cloudcli-install` и т.п.) — уточнить перед удалением.
- `~/storage/` — симлинки на внешнюю память Android.

## Диагностика

- **Общая картина:** `du -sh ~/.* ~/* 2>/dev/null | grep -E '^\s*[0-9.]+[MG]' | sort -hr | head -25`
- **Визуальный просмотр:** `ncdu ~` — стрелки для навигации, `d` для удаления, `q` для выхода.
- **Найти жирные node_modules:** `find ~ -maxdepth 5 -type d -name node_modules 2>/dev/null | xargs -I{} du -sh {} | sort -hr | head`
- **Найти забытые tarball:** `find ~ -maxdepth 2 -type f \( -name "*.tgz" -o -name "*.tar.gz" \) -exec ls -lh {} \;`

## pnpm store: как найти активную версию

pnpm имеет разные форматы сторов (`v10`, `v11`, ...). Активна только **последняя** — остальные это мёртвый груз от старых pnpm.

```bash
ls -1v ~/.local/share/pnpm/store | grep '^v[0-9]' | tail -1  # активная
```

Всё, что старше — удаляй без сомнений.

## Готовый ярлык

На устройстве уже есть `~/.shortcuts/cleanup.sh` — виджет-очистка. Показывает before/after MB. Пользователю не нужно ничего вводить руками — один тап.

Если ярлыка нет — создать по шаблону выше (см. пункты «Что можно чистить безопасно»).

## Правила общения с пользователем

- Пользователь — новичок, шелла не читает.
- Перед `rm -rf` любой папки объяснить простыми словами: что это, что случится, что перекачается.
- Показывать эффект в мегабайтах, а не в шелл-выводе.
- Не удалять то, в чём не уверен на 100% — сначала спросить.

## Родственные скилы

- `termux-widget-shortcuts` — как оформлять и подключать виджет.
- `termux-packages-instal` — установка пакетов (например, `ncdu`).
- `sync-skills` — синхронизация этого скила между `~/.agents/skills/` и `/sdcard/.EasyCode/skills/`.
